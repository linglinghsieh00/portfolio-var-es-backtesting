# Monte Carlo Simulation VaR & Expected Shortfall

## Objective
Estimate one-day 95% and 99% VaR and ES using
multivariate normal Monte Carlo simulation.

## Methodology
- Five-ETF portfolio
- 500-day rolling estimation window
- Multivariate normal return simulation
- 100,000 simulated scenarios
- Fixed portfolio weights
- One-day-ahead risk forecasts

## Validation
Compare simulated VaR and ES with analytical
Parametric Normal VaR and ES.
