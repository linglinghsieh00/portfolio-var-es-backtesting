# VaR & Expected Shortfall Backtesting

## Objective
Evaluate the out-of-sample performance of three VaR/ES models:
1. Historical Simulation
2. Parametric Normal
3. Monte Carlo Normal

## Methodology
- 500-day rolling estimation window
- 1-day-ahead forecasts
- 95% and 99% confidence levels
- VaR exception analysis
- Kupiec POF test
- Christoffersen independence and conditional coverage tests
- Expected Shortfall evaluation
